# Building System

A simple building system for Roblox. Choose a block, move the preview, and place it in the test area.

## Controls

Q: Equip the last block or cancel building
F: Switch block
R: Rotate block
G: Change grid size
X: Turn delete mode on or off
Left mouse: Place or delete a block

## Note

This is a client-side demo. The server does not check or save placed blocks.
